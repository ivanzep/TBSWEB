    What do I do with this?

    If you have this repo cloned locally:

    1. Click Save into repo folder… (Chrome/Edge) and pick this version's versions/<id>/ folder — it writes videos.json straight there. Otherwise, click Download and move the file into versions/<id>/videos.json yourself.
    2. Run ./scripts/scan.sh (or push — the CI workflow will regenerate it for you).
    3. Commit and push.

    If you're working through GitHub's website:

    1. Click Copy JSON.
    2. On GitHub, open versions/<id>/, click Add file → Create new file, name it videos.json, paste the copied content, and commit.
    3. The scan workflow picks it up automatically within about a minute — no local steps needed.
